# SanatanaAI Roadmap

## Phase 0: Foundation

- Establish governance and project memory.
- Define architecture and ADR process.
- Define agent contracts and artifact schemas.
- Define mission/task lifecycle and checkpoints.
- Define source, passage, claim, entity, relationship, and article foundations.
- Establish reproducible development and CI validation.

## Phase 1: Agent Runtime

- Agent registry and versioning.
- Contract validation.
- Agent execution abstraction.
- Permissions and policy enforcement.
- Structured artifact exchange.
- Retry, timeout, failure, and checkpoint primitives.

## Phase 2: Mission Orchestration

- Mission creation and decomposition.
- Planning and delegation.
- Dependency-aware task execution.
- Parallel execution.
- Resume from checkpoint.
- Real-time and batch execution policies.

## Phase 3: Evidence and Provenance

- Source registry.
- Source acquisition and metadata.
- Text/manuscript and passage records.
- Evidence references.
- Provenance graph.
- Reproducible processing records.

## Phase 4: Knowledge Model

- Ontology.
- Entities and relationships.
- Chronology and geography.
- Terminology and multilingual identifiers.
- Contradiction and competing interpretation representation.

## Phase 5: Research Pipeline

- Source discovery.
- Acquisition.
- Extraction and OCR.
- Translation and transliteration.
- Claim extraction.
- Evidence analysis.
- Cross-reference.

## Phase 6: Validation

- Source quality.
- Citation validation.
- Provenance validation.
- Claim validation.
- Contradiction detection.
- Hallucination safeguards.

## Phase 7: Encyclopedia Generation

- Article planning.
- Evidence-backed drafting.
- Editorial validation.
- Multilingual generation.
- Publication records.

## Phase 8: Real-time Research and Q&A

- Query understanding.
- Low-latency evidence retrieval.
- Research planning.
- Evidence-backed answer generation.
- Citation and provenance checks.

## Phase 9: Batch Research

- Large-scale mission execution.
- Parallel processing.
- Checkpointing and resumability.
- Cost and throughput controls.
- Incremental publication.

## Phase 10: Web Application

- Encyclopedia browsing.
- Research interface.
- Provenance and evidence views.
- Search and discovery.

## Phase 11: Android Application

- Mobile research and encyclopedia experience.
- Offline-aware caching where justified.
- Shared backend contracts with web.

## Phase 12: Autonomous Engineering

- Engineering agents.
- Automated test and security agents.
- Documentation agents.
- CI/CD agents.
- Release automation.

## Phase 13: Production Hardening

- Reliability.
- Security.
- Observability.
- Performance.
- Data quality.
- Disaster recovery.
- Operational governance.
